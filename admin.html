🔑 Đăng nhập / Đăng ký qua Discord (Discord OAuth2 Login)

Cho phép khách hàng đăng nhập và đăng ký bằng tài khoản Discord để shop dễ dàng kiểm soát, xác thực và quản lý Buyer Discord.

Bật OAuth
Lấy tại Discord Developer Portal → Ứng dụng của bạn → OAuth2 → General.
Mã bí mật Client Secret để xác thực token người dùng.
📌 Redirect URI (Dán vào mục OAuth2 → Redirects trên Discord Developer Portal):
https://vietnamlegacy.com/api/auth/discord/callback
💡 Hướng dẫn kích hoạt 3 bước:
1. Truy cập Discord Developer Portal → Bấm New Application (đặt tên shop của bạn).
2. Chọn menu OAuth2 bên trái → Bấm Add Redirect → Dán URL Redirect ở trên vào → Bấm Save Changes.
3. Copy Client ID và Client Secret dán vào 2 ô bên trên và bấm nút Lưu cấu hình Discord bên dưới.
